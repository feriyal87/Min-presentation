# 5 saker jag vill lära mig

## 1. C#
Jag vill lära mig programmeringsspråket **C#** och förstå grunderna i programmering så att jag kan skriva egna program.

## 2. Git och GitHub
Jag vill förstå hur **Git och GitHub** fungerar och kunna använda dem i mitt arbete och mina projekt.

## 3. Bygga appar
Jag är intresserad av att lära mig hur man **bygger appar**, från idé och planering till färdig app.

## 4. Datasäkerhet
Jag vill lära mig om **datasäkerhet**, bland annat hur man skyddar information, system och användare från olika säkerhetshot.

## 5. Använda AI
Jag vill lära mig **hur man använder AI** på ett effektivt sätt, både som verktyg för lärande och för att skapa och lösa olika typer av problem.

---

## Mitt mål

Jag vill utveckla mina kunskaper inom **programmering, apputveckling, datasäkerhet och AI**, och kunna använda dessa kunskaper i egna projekt.
